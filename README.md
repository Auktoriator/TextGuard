# TextGuard

Paper-Plugin für Minecraft Java 26.3, das pro Spielergruppe festlegt, welche Texte (Schilder, Bücher, Mob-Namen) ein Spieler lesen kann. Ausgeblendet wird nur im Netzwerkpaket an den jeweiligen Spieler; Welt und Items behalten immer den echten Text.

## Voraussetzungen

- Paper 26.3
- Java 25
- PacketEvents 2.14.0 oder neuer (https://modrinth.com/plugin/packetevents)
